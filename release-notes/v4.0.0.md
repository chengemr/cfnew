基于原版 v3.1 整合 Work 优化版，更新管理页面并将维护源码模块化。
现有环境变量、KV 绑定 `C`、KV 数据格式及单文件部署方式继续兼容，无需迁移配置。

## 下载与部署

- **Pages.zip**：Pages 部署包，ZIP 根目录仅包含 `_worker.js`。
- **_worker.js**：可直接部署的明文 Worker。
- **_worker.obfuscated.js**：功能一致的混淆 Worker；用于 Pages 时重命名为 `_worker.js`。
- **SHA256SUMS.txt**：以上三个下载文件的 SHA256 校验值。
- **Source code**：该版本完整仓库源码；开发入口位于 `src/`，不要将源码 ZIP 直接上传到 Pages。

兼容日期继续使用 `2026-01-20`。保留现有域名、变量与 KV 绑定；使用上传方式部署的项目，下载 `Pages.zip` 后按原流程更新。

## 主要修改

- 管理页面支持手机布局、中文／波斯语、差量保存、失败重试及优选节点导入与筛选。
- 源码按配置、KV、路由、页面、订阅和传输拆分；构建可复现，部署仍为单文件。
- 修复 KV 失败读取和配置覆盖保护、缓存隔离与刷新问题。
- 严格校验域名、端口与 IPv6，保留多级管理路径。
- 改进 Clash 节点专用 DNS 与选择策略，修复 Sing-box DNS 地址、端口及路径解析。
- 修复 SOCKS／WS 连接清理、XHTTP 截断报文与上传异常、家宽源请求超时。
- 仅启用 XHTTP 时，原生订阅保留；不支持 XHTTP 的转换目标返回明确提示，避免生成无法连接的节点。
- 页面、文档和两份部署产物统一标注 `v4.0.0`；保留轻量版及历史版本说明。

## 已知限制

本地测试及 Pages 试运行不能替代所有客户端在用户公网环境中的 TLS／代理连接验收。
Cloudflare KV 跨 isolate 仍为最终一致。延迟探测依赖原外部端点和 CORS，暂不支持 IPv6 探测；IPv6 配置和订阅仍可使用。
Trojan 转换沿用上游固定 TLS 的约定，非 TLS Trojan 在转换格式中仍存在原版限制。
发布 Release 不会自动部署或修改 Cloudflare 项目与 KV 数据。
