v4.0.2 是稳定性与安全修复版本，合并 [PR #5](https://github.com/chengemr/cfnew/pull/5)、[PR #6](https://github.com/chengemr/cfnew/pull/6) 和 [PR #7](https://github.com/chengemr/cfnew/pull/7)。正常配置、KV 格式、订阅和单文件部署继续兼容；没有增加功能。

## 下载与 Pages 部署

- **Pages.zip**：用于 Pages 上传部署，ZIP 根目录仅包含 `_worker.js`。
- **_worker.js**：可直接部署的明文 Worker。
- **_worker.obfuscated.js**：功能一致的混淆 Worker；用于 Pages 时重命名为 `_worker.js`。
- **SHA256SUMS.txt**：以上三个文件的 SHA256 校验值。
- **Source code**：完整开发源码，不是 Pages 部署包。

部署前确认 `u` 或 `U` 是有效 UUID，支持带连字符或 32 位十六进制格式。保留 KV 绑定 `C`、域名、管理路径和其他环境变量；兼容日期继续使用 `2026-01-20`。上传 `Pages.zip` 后，首页和管理页应显示 `v4.0.2`。

本版本不再回退到公开默认 UUID；缺失或非法 `U` 时返回 503 配置错误。配置 API 在写 KV 前拒绝错误类型、枚举、端口及无效优选批次，返回 400；空值重置、未知扩展字段、开关别名、可选空名称和现有非 HTTP DNS 格式继续兼容。

## 主要修复与整理

- DNS 转发遵循统一出站策略，`qj=only` 不再绕过指定代理；保留 `8.8.4.4:53` 目标和 DNS/TCP 帧，不使用 ProxyIP 的 443 端口作为 DNS 回退。
- TCP 打开、SOCKS/HTTP(S) 握手与 WS 首次写入共用 5 秒截止时间；客户端断开及时关闭待连接和竞速套接字。XHTTP 上传 EOF 后继续接收远端响应。
- SOCKS 认证按 UTF-8 字节计算长度；HTTP Basic 保留原 Latin-1 编码，超出 Latin-1 时支持 UTF-8。分片握手的读写锁在结束、取消和异常时释放。
- 优选源的请求头与正文共用 3 秒截止、最多 1 MiB；自定义首页为 5 秒、最多 2 MiB。失败、超时或超限沿用原有本地节点和默认首页回退。
- 优选名称最多 256 字符，不接受逗号、`#` 和换行，避免破坏现有 KV 存储格式；非法批次不部分保存。
- 合并重复出站顺序、UUID/IPv6 解析、字节转换与超时实现，改善 288 个局部标识符。`worker.js` 从 1703 行减至 484 行；纯重构使整个 `src/` 减少 91 行，计入稳定性防护后整体较 v4.0.1 增加 82 行。
- 保留 `scu`、`edgetunnel经典轻量版`、`snippets` 兼容入口；两个旧独立部署文件原样保留，现代 `src/` 的修复未同步到它们。
- 页面、文档、包版本和生成产物统一为 `v4.0.2`。CI 增加明文和混淆产物的 Chromium、Mihomo 检查；没有新增生产运行时依赖。

## 部署验收与限制

发布不会自动部署用户 Cloudflare 项目或修改 KV。部署后检查版本显示、配置保存和缓存刷新、三种订阅更新、实际客户端连接；启用 `qj=only` 时确认 DNS 和隧道流量都经过指定上游。遇到异常可回滚到上一部署。

公网 Pages、真实代理/TLS/ECH 和大规模并发需要用户部署后验收；本地与 CI 通过不能替代这些检查。跨 isolate KV 仍是最终一致。其他客户端兼容限制见 [Pages 更新说明](https://github.com/chengemr/cfnew/blob/v4.0.2/PAGES-UPDATE.md)。
