v4.0.5 修复 Clash／Mihomo 订阅的直连 DNS 配置：可直连的境外网站不再因通用 DNS fallback 不可达而导致连接超时。版本号、首页、管理页与两份部署文件已同步更新。

## 直连 DNS 修复

原配置中，`DIRECT` 连接沿用通用网站 DNS；主解析器返回境外 IP 时，GeoIP 过滤可能要求使用 Cloudflare／Google 的备用 DoH。备用 DNS 不可达时，即使关闭系统代理能够访问网站，开启系统代理后的直连连接仍可能超时。

- `direct-nameserver` 独立使用 `https://223.5.5.5/dns-query` 和 `https://119.29.29.29/dns-query`。
- 设置 `direct-nameserver-follow-policy: false`，直连出口不继承通用网站 DNS 策略。
- 覆盖 Apple 默认直连组和客户端手动追加的 MDPI 等 `DIRECT` 规则。
- 代理节点 DNS、自定义网站 DNS、其他网站 fallback 与原有策略组保持兼容。

## 下载与升级

- **Pages.zip**：Pages 部署包，ZIP 根目录仅包含 `_worker.js`。
- **_worker.js**：可独立部署的明文 Worker。
- **_worker.obfuscated.js**：混淆 Worker；用于 Pages 时重命名为 `_worker.js`。
- **SHA256SUMS.txt**：以上三个文件的 SHA256 校验值。
- **Source code**：开发源码，不是 Pages 部署包。

保留有效的 `u`／`U`、独立管理密钥 `ADMIN_TOKEN`、KV 绑定 `C`、域名和路径，上传新部署文件。兼容日期继续使用 `2026-01-20`，订阅链接与 KV 数据格式无需迁移。首页和管理页应显示 **v4.0.5**。

**部署后必须刷新 Clash Verge 订阅并重启内核**，新 DNS 配置才会应用。查看最终配置，确认 `direct-nameserver` 和 `direct-nameserver-follow-policy` 已生效；客户端扩展或 DNS 覆写可覆盖这些字段，需同步修改。

仅开启系统代理、需要沿用校园网 DNS 时，可在扩展脚本的 `return config;` 前加入：

```js
config.dns = config.dns || {};
config.dns["direct-nameserver"] = ["system://"];
config.dns["direct-nameserver-follow-policy"] = false;
```
