v4.0.4 完成项目审查发现的 11 项修复，包括管理权限隔离、配置保存、WS 回退、订阅转换和管理界面。原订阅链接、代理身份及 KV 数据格式保持兼容；管理认证需要新增环境密钥。

## 升级前必须设置管理密钥

在 Worker／Pages 环境添加独立 Secret `ADMIN_TOKEN`，使用 32–256 个字母、数字、`_` 或 `-`，建议随机生成 64 位十六进制值：

```sh
node -e 'console.log(require("node:crypto").randomBytes(32).toString("hex"))'
```

不要复用 `U`、Trojan 密码 `tp` 或自定义路径 `d`。密钥不存入 KV、订阅链接或浏览器持久化存储。未设置或不安全时管理入口返回 503，原订阅与代理仍可用。

更新后从首页输入原 UUID／自定义路径和管理密钥登录；管理 API 添加 `Authorization: Bearer <ADMIN_TOKEN>`。浏览器使用有效期 8 小时的签名 HttpOnly、SameSite=Strict 会话 Cookie，HTTPS 下带 Secure；写请求校验来源。退出清除当前浏览器 Cookie，轮换密钥使旧会话失效。

若部署 `edgetunnel经典轻量版` 或 `snippets`，需在文件顶部填写自己的 UUID；两份文件默认凭据留空，拒绝原公开示例 UUID，不读取 `u/U` 环境变量。

## 下载与 Pages 部署

- **Pages.zip**：Pages 部署包，ZIP 根目录仅包含 `_worker.js`。
- **_worker.js**：可独立部署的明文 Worker。
- **_worker.obfuscated.js**：混淆 Worker；用于 Pages 时重命名为 `_worker.js`。
- **SHA256SUMS.txt**：以上三个文件的 SHA256 校验值。
- **Source code**：开发源码，不是 Pages 部署包。

保留有效的 `u`／`U`、KV 绑定 `C`、域名和管理路径；新增 `ADMIN_TOKEN` 后上传部署文件。兼容日期继续使用 `2026-01-20`，无需迁移 KV。首页和管理页应显示 **v4.0.4**。

## 修复行为

- **独立管理权限**：订阅凭据不再授权配置、优选和状态接口；管理页面和 API 分别支持会话及 Bearer 认证。登录请求限制正文大小与读取时间，拒绝跨来源浏览器请求。
- **兼容入口身份**：不再允许直接使用仓库公开 UUID 部署两份旧入口；缺失或无效身份返回 503。
- **保存刷新**：合并变更前完整读取 KV，绕过应用缓存和版本快捷路径；刷新失败时拒绝保存并保留已有缓存。修复顺序保存时旧缓存回滚字段的问题。
- **WS 回退**：VLESS／Trojan 首字节回退重放初始及后续 WS 消息的完整上传，处理拨号期间新消息及旧连接迟到的写入结果。上传历史与待处理字节共享 256 KiB 预算。
- **Trojan 转换**：`security=none` 在 Sing-box 中保持明文 WS；Clash、家宽和 INI 过滤无法表达的明文 Trojan，过滤后没有节点返回 422。
- **XHTTP 端口**：不生成 Cloudflare HTTP 端口上的 TLS 节点，过滤后无节点返回明确失败。
- **Surge 订阅**：没有兼容的 TLS Trojan 时返回 422，避免成功返回只有直连的配置。
- **INI 密码**：含逗号、CR 或 LF 的 Trojan 密码对不支持该密码表示的 INI 目标返回 422；原生、Clash、Sing-box 等可表达格式保留密码。
- **家宽 YAML**：代理组引用与节点名称使用同一转义，正确处理引号和反斜线。
- **管理界面**：DNS 输入接受后端支持的 TLS、QUIC、UDP、裸主机和 IPv6 等格式；首页支持带连字符及紧凑 32 位 UUID。

## 部署验收与边界

发布 Release 不会自动更新用户的 Cloudflare 项目或生产 KV。部署后检查管理登录、保存与刷新、订阅更新以及实际客户端连接。不兼容格式现在返回 422，客户端是否保留旧配置由客户端决定。

Cloudflare KV 仍为最终一致存储；保存前刷新修复应用缓存问题，不提供跨实例强一致读取或原子事务。同时修改配置仍需考虑冲突。本地与 CI 检查不能代替公网部署和实际代理出口验收。其他限制见 [Pages 更新说明](https://github.com/chengemr/cfnew/blob/v4.0.4/PAGES-UPDATE.md)。
