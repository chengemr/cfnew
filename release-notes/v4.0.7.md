## 管理登录与项目链接

- 未登录或会话过期时，管理页跳转到 `/{UUID或自定义路径}/login`，不再被自定义首页挡住。退出后也返回此登录页，语言偏好保留。
- 独立入口支持 UUID、紧凑 UUID、多级路径和路径恰好为 `/login` 的部署。表单从当前 URL 预填路径，页面不嵌入管理密钥。
- 根路径原有登录方式和自定义首页继续保留。
- 首页和管理页的“项目与文档”指向 `chengemr/cfnew`；仓库地址集中维护，页面版本直接读取包版本，避免再次遗漏。

## 订阅 DNS 与来源失败退避

- Surge、Loon、Quantumult X 分别按客户端支持的字段输出自定义 DNS，保留地址、端口、路径和传输协议。
- 不能在目标格式中表达的 DNS 协议返回 422；不再把 `tls://`、`quic://`、`udp://` 截成 `tls:`、`quic:`、`udp:` 并返回成功。
- 优选来源首次失败、或旧数据超过有效期后，也暂停重试 15 秒。期间没有可用来源时仍返回 503，到期可恢复读取；切换来源 URL 不受另一来源的失败缓存影响。
- 成功节点缓存仍为 3 分钟，失败回退数据最长为成功获取后 15 分钟，失败不延长寿命。

## WS 自动重放策略

- 已经尝试写出的明文或其他不安全应用数据不再自动重放，避免服务端已执行、但 3.5 秒内未响应的明文 POST 被重复执行。
- 慢响应继续由原连接接收。没有写出应用数据前的拨号失败，以及可确认安全、完整且不含 early_data 的 TLS ClientHello，仍保留回退。
- TLS 记录和握手可跨 WS 消息拆分，允许 ClientHello 后的单个合法 TLS 1.3 兼容 CCS 记录；TLS early_data、额外应用记录和无法确认安全的内容不作为可重放数据。
- 首次写入仍受原 5 秒连接截止时间约束；写入失败可能已经交付部分数据，也不会无条件重发不安全请求。

自动重试无法为任意应用协议提供透明的恰好一次执行保证。新策略优先避免已发送请求的重复副作用；某些非 TLS 协议不再通过首字节超时自动切换连接。

## 下载与升级

- **Pages.zip**：ZIP 根目录仅含 `_worker.js`，用于 Pages。
- **_worker.js**：明文 Worker。
- **_worker.obfuscated.js**：混淆 Worker；用于 Pages 时重命名为 `_worker.js`。
- **SHA256SUMS.txt**：三个部署文件的 SHA256 校验值。

保留现有环境变量、KV 绑定 `C`、域名及路径，上传新部署文件并刷新客户端订阅。页面应显示 **v4.0.7**。如使用自定义 DNS，请确认目标客户端支持所选协议；不支持时接口会明确返回 422。

GitHub Release 不会自动更新现有 Cloudflare 部署。Cloudflare KV 的最终一致性限制仍保留，本地及 CI 的隔离检查不能替代实际网络中的客户端连接验收。
